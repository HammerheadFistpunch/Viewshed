APRS Viewshed Generator – UtahTurnkey VHF coverage analysis for the Utah APRS digipeater/iGate network---What it doesReads your scraped `utah_stations_scraped.json`Auto-downloads 3DEP 10m DEM elevation data for all of Utah (~400MB, cached after first run)Computes a WhiteboxTools viewshed for every station accounting for terrainMerges all viewsheds into a coverage count raster (pixel value = # of stations visible)Exports a KMZ with:Semi-transparent color overlay (yellow=1 station → red=max coverage)Station markers (red = digi, blue = igate) with callsign/comment popupsLegend---Quick Start```bash# 1. Put these files in the same folder as utah_stations_scraped.json:#    aprs_viewshed_utah.py#    requirements.txt# 2. Run it (installs deps automatically, or pre-install with pip):pip install -r requirements.txtpython aprs_viewshed_utah.py# 3. When done, open Google Earth Pro and load:#    aprs_coverage_utah.kmz#    your historical track KMZ```First run: ~5-15 minutes (DEM download + ~100 viewsheds)  Subsequent runs: ~3-5 minutes (DEM cached in `aprs_viewshed_work/utah_dem.tif`)---ConfigurationEdit the `CONFIG` block at the top of `aprs_viewshed_utah.py`:Setting	Default	Description`include_types`	`["digi","igate"]`	Filter to just digis: `["digi"]``antenna_height_digi_m`	`10`	Antenna height AGL in meters for digis`antenna_height_igate_m`	`6`	Antenna height AGL for igates`observer_height_m`	`2`	Mobile unit height (receiving end)`max_radius_km`	`80`	Max viewshed radius per station`dem_resolution`	`"10m"`	`"10m"` (USA, best) or `"30m"` (faster)`overlay_alpha`	`160`	PNG transparency (0=opaque, 255=invisible)`color_scheme`	`"hot"`	`"hot"` (yellow→red) or `"cool"` (green→blue)---Comparing Against Historical Tracks in Google EarthLoad `aprs_coverage_utah.kmz` — this is your predicted coverageLoad your historical track KMZ — this is actual heard packetsTracks inside the colored overlay = model agrees ✅Tracks outside the overlay = station heard despite terrain blockage (anomalous propagation, ducting, etc.) 🤔Areas with coverage overlay but no tracks = under-utilized or low-traffic areaTip: In Google Earth, right-click the coverage layer → Properties → adjust opacity slider in real-time to see the map underneath while comparing.---Output Files```aprs_coverage_utah.kmz          ← Load this in Google Earthaprs_viewshed_work/  utah_dem.tif                  ← Cached 10m DEM (kept for re-runs)  coverage_count.tif            ← Raw coverage raster (open in QGIS)```The `coverage_count.tif` can also be opened in QGIS for further analysis — it's a standard GeoTIFF where pixel values = number of stations with line-of-sight.---Troubleshooting`py3dep` download fails — Script automatically falls back to SRTM 30m. Or set `"dem_resolution": "30m"`.WhiteboxTools first run is slow — It downloads a ~30MB binary on first run. This is normal.Memory error on large radius — Reduce `max_radius_km` to 50 or 60.Station outside Utah warning — One station (TCPIP, lon=-109.25) is near the WY border — this is fine, it's included.---DependenciesWhiteboxTools — viewshed computationpy3dep — 3DEP DEM downloaderrasterio — raster I/OPillow — PNG renderingpyproj — coordinate transformations
